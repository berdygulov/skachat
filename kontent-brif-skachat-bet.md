# Контент-бриф skachat.bet — опорные пункты по страницам

Для каждого типа страницы: **зачем страница нужна** → **что обязательно затронуть в тексте** → **куда и откуда линковать**.

---

## 1. Главная `/`

**Зачем:** визитка + сводный рейтинг, первая точка входа, должна закрывать общий запрос «букмекеры узбекистан» / «рейтинг букмекеров».

**Опорные пункты:**
- Кто вы и почему вам можно доверять — 2-3 предложения с отсылкой к `/o-nas/` (методология оценки), не расписывать подробно
- Таблица/блок топ-N букмекеров с рейтингом, бонусом, кнопками «Обзор» / «Скачать приложение»
- Короткий блок «как мы оцениваем букмекеров» (критерии: лицензия, вывод денег, live, мобильность, поддержка UZCARD/HUMO) — 4-6 пунктов, каждый пункт можно превратить в ссылку на соответствующий категорийный хаб
- Блок «популярные категории» — плитки на `/bukmekery/s-live-stavkami/`, `/na-kriptovaljutu/`, `/s-vyvodom-na-uzcard-humo/` и т.д.
- Блок «последние отзывы» (2-3 свежих UGC-отзыва с ссылкой на `/otzyvy/`) — сигнал свежести на главной
- Блок «статьи» — 3 карточки из `/stati/`
- Футер: обязательные ссылки на `/o-nas/`, `/otvetstvennaya-igra/`, `/faq/`, значки gambleaware/gamblingtherapy — на КАЖДОЙ странице сайта, не только на главной

**Линковка:**
- Отдаёт вес: на карточки брендов, на все хабы верхнего уровня
- Получает вес: ниоткуда (входная страница), поэтому именно сюда должны вести внешние ссылки/реклама

## 2. `/bukmekery/` — хаб-каталог

**Зачем:** закрывает широкий запрос «все букмекеры узбекистан», служит родителем для категорийных фильтров и карточек — структурный узел сайта.

**Опорные пункты:**
- Вводный текст 150-250 слов: что такое каталог, как им пользоваться, чем отличается от рейтинга на главной
- Полный список/сетка всех карточек брендов с ключевыми атрибутами (рейтинг, лицензия, бонус) — как и на bukmekerexpert.com, где всё через фильтры
- Блок фильтров (по факту — ссылки на категорийные хабы): по лицензии, по крипте, по live, по мобильности, по UzCard/Humo, оффшорные — сделать видимыми как навигационные чипы, а не просто текст
- Мини-объяснение критериев (без дублирования `/o-nas/`, 1 абзац с сылкой «подробнее о методологии»)

**Линковка:**
- Входящие: с главной, из футера/шапки (постоянный пункт меню)
- Исходящие: на каждую карточку бренда, на все категорийные хабы

## 3. Категорийные хабы `/bukmekery/[категория]/`

**Зачем (это ключевой инсайт из анализа bukmekerexpert.com):** дешёвый способ размножить индексируемые страницы без дублирования контента — один и тот же набор карточек, но под разные интенты.

**Опорные пункты (одинаковый шаблон для каждого хаба):**
- Уникальный intro-текст 300-500 слов **под конкретный интент категории**, не шаблонный — например для `na-kriptovaljutu`: какие крипто принимаются, есть ли комиссии, безопасно ли, регулируется ли это в Узбекистане
- Явно закрыть 2-3 вопроса из «люди также спрашивают» по этой категории (можно оформить как мини-FAQ в конце страницы)
- Список карточек-подмножества (те же брендовые карточки, что и в общем каталоге, но отфильтрованные)
- Короткая таблица сравнения именно по критерию хаба — это не дубль общей таблицы из каталога, а срез по одному конкретному параметру, ради которого человек зашёл на этот хаб. Данные для неё не нужно собирать отдельно — они уже есть на карточке бренда (лицензия, способы оплаты, дата основания и т.д.), таблица просто переупаковывает их под конкретный интент:

  | Хаб | Что сравниваем в таблице (столбцы) |
  |---|---|
  | `s-live-stavkami` | Задержка коэффициентов / наличие видео-трансляций / доступен ли кэшаут в live |
  | `mobilnye` | Наличие Android-приложения / наличие iOS-приложения / размер APK / оценка приложения |
  | `s-licenziej` | Юрисдикция лицензии / номер лицензии / регулятор |
  | `na-kriptovaljutu` | Какие криптовалюты принимает / комиссия на вывод / минимальная сумма депозита |
  | `s-vyvodom-na-uzcard-humo` | Поддержка UzCard / поддержка Humo / срок вывода / лимит на вывод |
  | `bez-verifikacii` | здесь таблица менее уместна — лучше текстовый блок: у большинства букмекеров «без верификации» на деле означает «без верификации до определённой суммы вывода», это бинарным да/нет не передать, и по теме важно писать честно, без завышенных ожиданий |

- **Локальная фишка — почему `s-vyvodom-na-uzcard-humo` и `bez-verifikacii` не такие, как остальные 4 хаба:**
  - `s-live-stavkami`, `mobilnye`, `s-licenziej`, `na-kriptovaljutu` — это стандартные категории, которые есть у большинства крупных конкурентов (bukmekerexpert.com, спортивные медиа-гиганты). Они универсальны для любого рынка — live-ставки и лицензия одинаково актуальны что в Узбекистане, что в Люксембурге
  - `s-vyvodom-na-uzcard-humo` — это про местные платёжные системы Узбекистана (UzCard, Humo). Международный конкурент, работающий на десятки стран, под них отдельный хаб делать не будет — слишком узко для его масштаба. А для локального пользователя это один из первых практических вопросов: сможет ли его карта вообще принять/вывести деньги
  - `bez-verifikacii` — тоже локально мотивированный запрос: связан с тем, что не у всех пользователей под рукой привычные для международных букмекеров документы/процедуры KYC, либо люди осторожничают и не хотят проходить верификацию
  - Практический вывод: это ниша, которую конкуренты не закрывают вообще или закрывают поверхностно — значит есть шанс сделать по ней самый подробный контент на рынке и ранжироваться за счёт глубины, а не за счёт борьбы за общие запросы вроде «live-ставки», где уже конкурируют крупные игроки. Поэтому задача не «указать UzCard: да/нет», а реально расписать по каждому букмекеру комиссии, сроки зачисления/вывода, лимиты — то, чего у конкурентов просто нет, потому что их аудитории это не нужно

**Список хабов из карты сайта:**
`s-live-stavkami`, `mobilnye`, `s-licenziej`, `na-kriptovaljutu`, `bez-verifikacii`, `s-vyvodom-na-uzcard-humo`

**Линковка:**
- Входящие: с `/bukmekery/`, с главной (плитки), контекстно из `/stati/`
- Исходящие: на карточки брендов, попавшие в фильтр (каждый бренд получает ссылку с 1-3 хабов одновременно — это и есть механика «узла»)

## 4. Карточка бренда `/bukmekery/[brand]/`

**Зачем:** главный конверсионный узел сайта, YMYL-страница — сюда должны стекаться ссылки минимум с 5 хабов.

**Опорные пункты (по инсайту bookmakers-uz.com — упор на формальные данные доверия):**
- Дата основания компании
- Юрлицо-владелец и юрисдикция лицензии (номер лицензии, если доступен)
- Адрес офиса / страна регистрации
- Членство в ассоциациях (IBAS, CPO и т.п.) — если есть
- Способы пополнения/вывода, актуальные для Узбекистана (UzCard, Humo, Click, Payme)
- Плюсы/минусы — честный, не рекламный тон
- Мини-навигация внутри карточки на дочерние страницы: скачать / бонусы / промокод / отзывы (это должно быть видно как таб-меню, а не просто в футере статьи)
- Блок «последние отзывы по этому бренду» (3-5 штук, с ссылкой «все отзывы →»)
- FAQ по бренду: «[бренд] развод или нет», «как вывести деньги с [бренд]», «есть ли лицензия у [бренд]»

**Линковка (ключевая механика перелинковки всего сайта):**
- Входящие ссылки должны идти минимум с 5 независимых мест:
  1. с главной (сводная таблица)
  2. с `/bukmekery/` (общий каталог)
  3. с 1-3 категорийных хабов, в которые попадает бренд
  4. с `/bonusy-i-promokody/` (через таблицу бонусов)
  5. со статей в `/stati/` — контекстные ссылки вида «для live-ставок хорошо подходит [бренд] →»
- Исходящие: на 4 дочерние страницы (`/skachat/`, `/bonusy/`, `/promokod/`, `/otzyvy/`) + на `/otzyvy/` (общий хаб) + в футере на `/o-nas/` и `/otvetstvennaya-igra/`

## 5. `/bukmekery/[brand]/skachat/`

**Зачем:** самый транзакционный трафик сайта, приоритет №1 по вашему плану.

**Опорные пункты:**
- Раздельные инструкции: Android (apk, где скачать, почему не в Google Play, как включить установку из неизвестных источников), iOS, рабочее зеркало
- Актуальная версия приложения / дата обновления — важно для freshness-сигнала
- Требования к устройству (минимальная версия ОС)
- Пошаговая инструкция установки (нумерованный список — хорошо ложится в разметку HowTo)
- Что делать, если ссылка не работает / зеркало заблокировано
- Короткий FAQ: «безопасно ли скачивать APK», «нужен ли VPN»

**Линковка:**
- Входящие: с карточки бренда (таб-навигация), с главной (кнопка «скачать» рядом с брендом в таблице)
- Исходящие: обратно на карточку бренда (обзор), на `/bukmekery/[brand]/bonusy/` («после установки заберите бонус за регистрацию →»)

**Зачем:** закрывает большой кластер спроса вокруг бонусов, отдельно приоритетный (п.3 плана).

**Опорные пункты для страницы бренда:**
- Актуальный бонус (сумма, %, условия отыгрыша — wager)
- Пошагово: как получить (регистрация → депозит → активация)
- Условия отыгрыша прописать честно, без завышенных ожиданий (важно для доверия/YMYL)
- Дата последней проверки актуальности бонуса

**Опорные пункты для хаба `/bonusy-i-promokody/` и подкатегорий (`bez-depozita`, `na-pervyy-depozit`, `fribety`):**
- Сводная таблица по всем брендам с типом бонуса
- Explainer-блок: чем депозитный бонус отличается от фрибета и безлепа — 150-200 слов
- Предупреждение про отыгрыш/вейджер как элемент ответственного отношения к продукту

**Линковка:**
- Входящие: с карточки бренда, с главной, из `/stati/` (статья «что такое промокод»)
- Исходящие: на `/bukmekery/[brand]/promokod/`, на карточку бренда

## 8. `/bukmekery/[brand]/otzyvy/` + `/otzyvy/`

**Зачем:** UGC-движок — не блок на странице, а отдельный источник свежего контента и E-E-A-T (Experience) сигнала, инсайт от sportreytingi.uz.

**Опорные пункты для общего хаба `/otzyvy/`:**
- Форма добавления отзыва — видна сразу, не спрятана
- Модерация: явно указать правила (без мата, без спама, проверка на реальность) — это тоже сигнал доверия
- Сортировка/фильтр по брендам, по рейтингу
- Явная формулировка «мнение авторов может не совпадать» / отказ от ответственности за пользовательский контент

**Опорные пункты для отзывов на карточке бренда:**
- Явный призыв «оставьте отзыв о [бренд]»
- Ответ администрации сайта на негативные отзывы (если возможно реализовать) — усиливает доверие сильнее, чем просто список отзывов

**Линковка:** двусторонняя с карточкой бренда, входящие с главной (блок «последние отзывы»)

## 9. `/stati/` и статьи

**Зачем (важно понимать иначе, чем остальные разделы):** это link magnet, а не money-страницы. Не конкурируют с прогнозами/карточками напрямую, работают на инфозапросы и получают внешние ссылки охотнее, чем страницы с партнёрскими ссылками.

**Опорные пункты (для каждой статьи):**
- Отвечать на конкретный неновостной, эвергрин-вопрос («как выбрать букмекера», «как работают live-ставки», «что такое промокод», «способы оплаты в Узбекистане», «как вывести деньги с букмекера») — без гонки за прогнозами на конкретные матчи
- Обязательно 2-3 контекстные ссылки внутри текста на релевантные карточки брендов или категорийные хабы (это и есть механизм передачи веса «дальше по воронке», описанный в анализе) — но не более, чтобы не выглядело как реклама
- Дата публикации/обновления — эвергрин-контент нужно периодически освежать, это тоже сигнал для Google

**Хаб `/stati/`:**
- Список всех статей, категоризация по темам (платежи, live, бонусы, безопасность)

**Линковка:**
- Входящие: с главной (блок «статьи»), из футера/меню
- Исходящие: на карточки брендов и категорийные хабы (контекстно, не списком ссылок в конце)

## 10. `/o-nas/`, `/faq/`, `/otvetstvennaya-igra/`

**Зачем:** не страницы для трафика, а страницы для доверия — ссылки на них должны быть в футере каждой страницы сайта, это E-E-A-T сигнал на уровне всего домена.

**Опорные пункты `/o-nas/`:**
- Кто команда, чем занимается сайт
- Методология оценки букмекеров — конкретные критерии с весами/баллами, не абстрактно
- Как часто обновляются данные (важно для YMYL)
- Контакты для связи/жалоб

**Опорные пункты `/faq/`:**
- Общие вопросы про сайт (не про конкретного букмекера — те уже в FAQ карточки бренда): «вы принимаете ставки?», «как вы зарабатываете (партнёрки)», «насколько объективен рейтинг»

**Опорные пункты `/otvetstvennaya-igra/`:**
- Признаки игровой зависимости
- Ссылки на внешние ресурсы помощи (gambleaware.org, gamblingtherapy.org — как у sportreytingi.uz и bukmekerexpert.com)
- Возрастное ограничение 18+
- Инструменты самоограничения, если букмекеры их предоставляют

**Линковка:** входящие — из футера ВСЕХ страниц сайта без исключения; исходящие — практически не нужны, это терминальные страницы доверия

## 11. `/uz/` — зеркало на узбекском

**Зачем:** самая ресурсоёмкая часть, но покрывает большой неохваченный спрос (узбекоязычные запросы).

**Опорные пункты:**
- Не отдельный сайт с урезанным контентом, а полное зеркало структуры выше, включая категорийные хабы и статьи
- **Технически обязательно:** `hreflang="ru"` / `hreflang="uz"` на каждой паре страниц — без этого Google может считать версии дублями или конкурентами вместо показа нужной аудитории
- Переключатель языка на каждой странице (как у bookmakers-uz.com и bukmekerexpert.com), не отдельный несвязанный поддомен

**Линковка:** зеркальная — та же структура перелинковки, что и в RU-версии, плюс взаимные hreflang-ссылки между парами страниц

## Сводная логика перелинковки (для копирайтера/SEO)

1. **Карточка бренда** — узел, получающий ссылки минимум с 5 источников (главная, каталог, 1-3 категорийных хаба, бонусы, статьи)
2. **Категорийные хабы** — не дублируют контент, а фильтруют один и тот же набор карточек под разные интенты; дают новые URL почти бесплатно
3. **Статьи** — не конкурируют с транзакционными страницами, а подпитывают их контекстными ссылками; их задача — внешние ссылки и охват инфозапросов
4. **Отзывы** — источник регулярно обновляемого UGC (freshness + E-E-A-T)
5. **Страницы доверия** (`/o-nas/`, `/otvetstvennaya-igra/`) — присутствуют в футере каждой страницы сайта, формируют E-E-A-T на уровне домена, а не отдельной страницы
6. **`/uz/`** — зеркало с hreflang, не отдельная ветка контента
