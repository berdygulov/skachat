## Конкуренты

Проверены напрямую в браузере десять источников, включая прямые попытки зайти по URL-паттернам `[бренд]-skachat`, `[бренд]-apk`, `[бренд]-bonus` на bookmakers-uz.com и kupon.tv (оба — 404, данные по установке у них только на общей карточке бренда). Шесть источников дали данные. **bukmekerlar-uz.com** (`/ru/1xbet-skachat-na-android/`) — выделенная страница: рейтинг 4.8, 945 скачиваний, обновлено 30.08.2026, версия v.135(16195), APK 83.4 Мб / приложение 209 Мб, минимум Android 5.0, файл проверен DrWeb, тезис «Отсутствие зеркал: ПО самостоятельно подключается к доступному серверу, минуя зеркала». **sporttikishuz.com** (`/1xbet-applications/`) — тоже выделенная страница: Android (мин. версия ОС — 4.1), iOS (только через App Store), Windows (две программы — «1xBrowser», обычный браузер для обхода блокировок, и «1xWin», полноценный клиент для ставок), явное «бонусов за установку нет», выбор языка подстраивается под ОС. **bookmakers-uz.com** (карточка бренда) — разделы «1xBet Приложения» (прямые ссылки на APK и AppStore) и «1xBet Зеркала» (пример рабочего зеркала). **betnbetuz.com** (`/ratings/bookmakers-for-android-uz`) — сравнительная таблица по 4 брендам: у 1xBet APK 52.35 Мб, приложение 137 Мб, версия v253.4.0, Android 5.0+. **ratingbet.com** — отдельная англоязычная страница «1xBet App Download» (гео Кения, не uz): APK ~48 Мб, Android 5.0+/100 Мб свободного места, iOS 8.0+/300 Мб. **ua-football.com** (`/betting/bookmakers/8-bukmeker-1xbet`) — полноценный обзор с разделами про установку: подтверждает установку Android через APK-файл напрямую с сайта 1xBet (не через Google Play), **iOS — через App Store** (совпадает с sporttikishuz.com — второй независимый источник на этом утверждении), десктопное приложение **«1xWin»** с пошаговой инструкцией установки (только это название, без «1xBrowser»). `bukmekerexpert.com` подтверждает лишь общий факт «Приложения для Android, iOS и Windows» без деталей (гео не uz). `sportreytingi.uz` и `ua.tribuna.com` не включают 1xBet в свой каталог брендов вообще.

**Бонус за установку приложения — прямое противоречие.** bukmekerlar-uz.com утверждает, что есть бонус 50% от суммы ставки (до 138 000 UZS). sporttikishuz.com пишет обратное: «Компания 1xBet не предоставляет бонусы за установку своих приложений». Взаимоисключающие утверждения, не вариация цифры — без проверки на самом сайте бренда ни один не должен подаваться как факт.

**Размер/версия APK — три разных набора цифр:** bukmekerlar-uz.com (83.4 Мб, v.135), betnbetuz.com (52.35 Мб, v253.4.0), ratingbet.com (~48 Мб, версия не указана). Точную версию/размер не публикуем как факт, отправляем проверять «в разделе «О приложении» после первого запуска».

**Минимальная версия Android** — 5.0+ у bukmekerlar-uz.com и betnbetuz.com, 4.1+ у sporttikishuz.com. Дан диапазон, не одна цифра.

**iOS-дистрибуция** — App Store подтверждён двумя независимыми источниками (sporttikishuz.com, ua-football.com), это самое надёжное из утверждений по установке на этой странице.

**Windows-приложение «1xWin»** — подтверждено двумя источниками (sporttikishuz.com, ua-football.com; у ua-football.com — с пошаговой инструкцией установки). Второе название, «1xBrowser», — только у sporttikishuz.com, отдельно не подтверждено.
