# Общее примечание по внедрению для всех 6 категорийных хабов `/bukmekery/[категория]/`

Букмекеры сайта: **Leon, Linebet, 1xBet, Xparibet, 888Starz, Betwinner, Melbet, Pin Up, Mostbet, Parimatch, 1Win**.

Эта версия заменяет плейсхолдеры на данные, проверенные по официальному реестру регулятора Curaçao Gaming Authority и по триангуляции независимых источников. Там, где данные не подтверждены надёжно, это указано явно — не заполнено выдумкой.

Общий блок относится сразу к нескольким хабам: [`s-licenziej/s-licenziej.md`](s-licenziej/s-licenziej.md), [`na-kriptovaljutu/na-kriptovaljutu.md`](na-kriptovaljutu/na-kriptovaljutu.md), [`s-vyvodom-na-uzcard-humo/s-vyvodom-na-uzcard-humo.md`](s-vyvodom-na-uzcard-humo/s-vyvodom-na-uzcard-humo.md), [`s-live-stavkami/s-live-stavkami.md`](s-live-stavkami/s-live-stavkami.md), [`mobilnye/mobilnye.md`](mobilnye/mobilnye.md), [`bez-verifikacii/bez-verifikacii.md`](bez-verifikacii/bez-verifikacii.md).

- **Leon** — доп. проверка от 11.08.2026 (сделанная при подготовке карточки бренда) подтвердила отзыв лицензии Curaçao и нашла вероятную текущую лицензию Anjouan через Jade Reef Ventures Corp., плюс официальное предупреждение ACMA (Австралия, январь 2026). Это надёжнее, чем было известно раньше, но новая лицензия подтверждена только вторичными источниками — перед публикацией в `s-licenziej` нужна ручная проверка сертификата на сайте бренда. В остальных хабах (крипта, UzCard/Humo, верификация) данные по Leon относительно надёжны и публиковать можно. Полная версия — в `tekst/bukmekery/brendy/leon/bukmeker-leon.md`.
- **Parimatch** — доп. проверка от 11.08.2026 нашла правдоподобную версию держателя лицензии (Castianes B.V., OGL/2024/1329/0629), но не смогла подтвердить её напрямую через cert.cga.cw (403 при проверке). По-прежнему самый проблемный бренд по количеству неподтверждённых данных сразу в нескольких хабах (лицензия, крипта, UzCard/Humo) — решение о временном исключении из категорийных хабов до финальной проверки остаётся в силе. Полная версия — в `tekst/bukmekery/brendy/parimatch/bukmeker-parimatch.md`.
- **888Starz и 1Win** — лицензия подтверждена по названию юрлица в официальном реестре, но не по сертификату на сам домен. Формулировки в тексте — «работает по лицензии Curaçao» без точного номера, пока не сверено дополнительно.
- Хабы `s-live-stavkami` и `mobilnye` пока публикуются без таблицы сравнения по брендам — надёжных данных для неё нет, а ручное тестирование пока не проводится. Это можно доработать позже без нового раунда поиска.
- Раздел `s-licenziej` стоит обновлять чаще остальных — ситуация с лицензированием в Узбекистане и статусы у CGA активно меняются.
- В блоках `na-kriptovaljutu` и `bez-verifikacii` намеренно избегал формулировок, которые звучат как поощрение обхода правил — упор сделан на честное объяснение, как это работает на практике, а не на продажу идеи «анонимности».
