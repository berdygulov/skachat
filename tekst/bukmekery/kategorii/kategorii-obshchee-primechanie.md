# Общее примечание по внедрению для всех 6 категорийных хабов `/bukmekery/[категория]/`

Букмекеры сайта: **Leon, Linebet, 1xBet, Xparibet, 888Starz, Betwinner, Melbet, Pin Up, Mostbet, Parimatch, 1Win**.

Общий блок относится сразу к нескольким хабам: [`s-licenziej/s-licenziej.md`](s-licenziej/s-licenziej.md), [`na-kriptovaljutu/na-kriptovaljutu.md`](na-kriptovaljutu/na-kriptovaljutu.md), [`s-vyvodom-na-uzcard-humo/s-vyvodom-na-uzcard-humo.md`](s-vyvodom-na-uzcard-humo/s-vyvodom-na-uzcard-humo.md), [`s-live-stavkami/s-live-stavkami.md`](s-live-stavkami/s-live-stavkami.md), [`mobilnye/mobilnye.md`](mobilnye/mobilnye.md), [`bez-verifikacii/bez-verifikacii.md`](bez-verifikacii/bez-verifikacii.md).

- **Leon** — доп. проверка от 11.08.2026 подтвердила отзыв лицензии Curaçao и нашла вероятную текущую лицензию Anjouan через Jade Reef Ventures Corp. по вторичным источникам. Повторная проверка 19.08.2026 напрямую на leonbets.com подтвердила это по первичному источнику — в футере сайта прямым текстом указаны компания Jade Reef Ventures Corp. (рег. номер 42967, Белиз) и лицензия Anjouan № ALSI-202410001-FI1, плюс официальное предупреждение ACMA (Австралия, январь 2026). Ручная проверка больше не нужна — все данные по лицензии Leon подтверждены, можно публиковать без оговорок во всех хабах. Полная версия — в `tekst/bukmekery/brendy/leon/bukmeker-leon.md`.
- **Parimatch** — доп. проверка от 11.08.2026 нашла правдоподобную версию держателя лицензии (Castianes B.V., OGL/2024/1329/0629), но не смогла подтвердить её напрямую через cert.cga.cw (403 при проверке). Повторная проверка 19.08.2026 напрямую через cert.cga.cw и через сайт parimatch.com/parimatchde.net — снова отрицательный результат: на сайте бренда нет кликабельной печати CGA, а в «Условия и положения» юрлицо-держатель и номер лицензии не названы вообще. Это уже вторая независимая попытка с тем же итогом — похоже, дело не в пробеле поиска, а в сознательной непрозрачности оператора; не повторять проверку тем же способом без новой зацепки. По-прежнему самый проблемный бренд по количеству неподтверждённых данных, но исключение точечное, не по всем хабам разом: в `s-live-stavkami` и `mobilnye` (уже опубликованы) Parimatch присутствует как обычный 11-й бренд — по этим темам проблем с данными не было. Исключён он только там, где данные конкретно по этой теме не подтверждены: `s-licenziej` (лицензия), `na-kriptovaljutu` (крипта, не подтверждена ни в одном источнике — см. `na-kriptovaljutu/na-kriptovaljutu.md`) и теперь `s-vyvodom-na-uzcard-humo` — доп. раунд от 21.08.2026 нашёл ещё один сторонний источник (betnbetuz.com), подтверждающий UzCard/Humo для Parimatch без оговорок, но это тот же уровень источника, что и раньше, неопределённость не снята; решение на этом хабе — исключить Parimatch из подмножества (блок 3), см. `s-vyvodom-na-uzcard-humo/s-vyvodom-na-uzcard-humo.md`. По `bez-verifikacii` (доп. раунд 21.08.2026, см. `bez-verifikacii/head-klyuchi.md`) — Parimatch не отличается от остальных 10 брендов по этой теме: у всех верификация запускается «по усмотрению букмекера» без фиксированного порога, отдельной проблемы с данными именно по Parimatch нет — включён в хаб как обычный 11-й бренд, исключения не требуется. Полная версия — в `tekst/bukmekery/brendy/parimatch/bukmeker-parimatch.md`.
- **888Starz и 1Win** — лицензия подтверждена по названию юрлица в официальном реестре, но не по сертификату на сам домен. Формулировки в тексте — «работает по лицензии Curaçao» без точного номера, пока не сверено дополнительно.
- Хаб `s-live-stavkami` публикуется без таблицы сравнения по брендам — надёжных данных для неё нет ни в одном источнике, а ручное тестирование live-раздела (задержка коэффициентов, кэшаут, видео по каждому из 11 брендов) не проводится и не планируется. Это постоянное решение, а не временный пробел — см. обоснование в `s-live-stavkami/s-live-stavkami.md` (блок 4).
- Хаб `mobilnye` публикуется без таблицы сравнения по брендам — проверка размера APK по всем 11 брендам (см. `mobilnye/head-klyuchi.md`) показала разброс в разы у каждого бренда в зависимости от источника (сторонние APK-каталоги нередко хостят чужой софт под именем бренда), а официальные сайты части брендов недоступны напрямую. Как и с `s-live-stavkami`, это не временный пробел, а результат реальной попытки собрать данные — см. обоснование в `mobilnye/mobilnye.md` (блок 4).
- Хаб `s-vyvodom-na-uzcard-humo` публикуется со всеми 4 столбцами брифа, но на разных уровнях достоверности: «UzCard»/«Humo» (да/нет) — надёжный факт, без оговорок; «срок вывода»/«лимит на вывод» — округлённые ориентиры с явной сноской (данные одного стороннего источника на бренд, не с официального сайта). Собирались в 2 раунда (21.08.2026): первый — живой обход официальных сайтов через браузер (доступны не все, данные нашлись только через сторонних обзорников); второй — доп. поиск, закрывший пробелы по Linebet и Xparibet и уточнивший данные по 888Starz. Единственное исключение — лимит по 1xBet: явный выброс у исходного источника (минимум по Humo в 30+ раз выше минимума по депозиту того же источника), не публикуется вообще, даже округлённо. Полное обоснование и все цифры — в `s-vyvodom-na-uzcard-humo/head-klyuchi.md` и `s-vyvodom-na-uzcard-humo/s-vyvodom-na-uzcard-humo.md` (блок 4). В отличие от `s-live-stavkami`/`mobilnye`, где решение — не публиковать всю таблицу целиком, здесь решили не молчать о данных, раз они в основном нашлись, а показать с честной оговоркой.
- Хаб `bez-verifikacii` публикуется без таблицы сравнения по брендам — по брифу для этого хаба это ожидаемо (табличный формат явно назван менее уместным, чем текстовый блок). Два раунда живого обхода/поиска (21.08.2026) подтвердили, что фиксированного порога суммы для верификации не существует ни у одного из 11 брендов как цифры — решение «по усмотрению» службы безопасности, а не пробел в данных. Блок 1 также явно указывает на упрощение у одного из конкурентов (заявляет «верификация не требуется» как факт по отдельным брендам, без разъяснения механики «по усмотрению») — см. `bez-verifikacii/head-klyuchi.md` и `bez-verifikacii/bez-verifikacii.md` (блок 4).
- Раздел `s-licenziej` стоит обновлять чаще остальных — ситуация с лицензированием в Узбекистане и статусы у CGA активно меняются.
- В блоках `na-kriptovaljutu` и `bez-verifikacii` намеренно избегал формулировок, которые звучат как поощрение обхода правил — упор сделан на честное объяснение, как это работает на практике, а не на продажу идеи «анонимности».
