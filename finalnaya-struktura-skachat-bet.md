| **bukmekerexpert.com** | Самая зрелая структура из всех виденных: каталог букмекеров разбит на **категории-фильтры** (по лицензии, по крипте, по live, по мобильности, оффшорные/зарубежные), бонусы — тоже на категории (депозитные/бездепозитные/фрибеты). Это даёт кучу дополнительных индексируемых страниц-хабов, которые ссылаются на одни и те же карточки брендов — то есть один и тот же букмекер получает ссылки с 3-4 разных хабов |
| **bookmakers-uz.com / bukmekerexpert.com** | Оба — двуязычные (RU/UZ) через переключатель языка на каждой странице, а не отдельный несвязанный поддомен |
| **ua-football.com, ua.tribuna.com** | Букмекерская вертикаль внутри крупного спортивного медиа: `/betting/bookmakers/[brand]/app` — то есть даже медиа-гиганты держат отдельную "скачать"-страницу под каждый бренд |

Главный вывод: **категорийные хабы-фильтры — это то, чего нет ни у одного из ваших первых 15 конкурентов, но есть у самого сильного (bukmekerexpert.com)**. Это дешёвый способ размножить точки входа в карточки брендов без дублирования контента.

## Как это работает как система перелинковки

**1. Карточка бренда — это узел, в который стекаются ссылки минимум с 5 разных хабов одновременно:**
- с главной (сводная таблица)
- с `/bukmekery/` (общий каталог)
- с 1-3 категорийных фильтров (например, Mostbet попадёт одновременно в «с live-ставками», «мобильные», «с выводом на UzCard/Humo»)
- с `/bonusy-i-promokody/` (через таблицу бонусов)
- со статей в `/stati/` (контекстные ссылки: «для live-ставок хорошо подходит Mostbet →»)

Это именно то, что делает bukmekerexpert.com сильнее конкурентов формата «просто один список брендов» — один и тот же продвигаемый URL получает внутренний вес с нескольких независимых страниц, а не только с главной.

**2. Категорийные хабы — это не дублирование контента, а фильтр одного и того же набора карточек.** Технически на каждой странице выводится подмножество уже существующих карточек брендов с уникальным intro-текстом под конкретный запрос («букмекеры с криптовалютой в Узбекистане» — 300-500 слов уникального текста + карточки). Это даёт новые индексируемые URL почти бесплатно.

**3. Статьи (`/stati/`) — это link magnet, а не money-страницы.** На них не льют прямой трафик из платной рекламы, зато они:
- ранжируются по информационным запросам, которые не конвертируются напрямую, но приводят аудиторию на сайт
- получают внешние ссылки (гайды чаще линкуют, чем на рейтинги с афилиат-ссылками)
- внутри содержат контекстные ссылки на карточки брендов — передают вес дальше по воронке

**4. Отзывы (`/otzyvy/` + блок на карточке бренда) работают в двух направлениях:**
- общий хаб `/otzyvy/` ранжируется по запросу «отзывы букмекеров узбекистан»
- отзывы под конкретным брендом добавляют уникальный, регулярно обновляемый UGC-контент на карточку — это сигнал свежести (freshness) для Google и E-E-A-T (Experience) в YMYL-нише

**5. `/uz/` не отдельный сайт, а зеркало с hreflang.** Разметка `hreflang="ru"` / `hreflang="uz"` на каждой паре страниц — иначе Google может считать русскую и узбекскую версию дублями или конкурирующими страницами вместо того, чтобы показывать нужную версию нужной аудитории.

**6. `/o-nas/` и `/otvetstvennaya-igra/` — это не страницы для трафика, а страницы для доверия.** Ссылки на них должны быть в футере на **каждой** странице сайта — так Google видит сигнал E-E-A-T на уровне всего домена, а не одной страницы.

## Что делать в первую очередь

1. Карточки брендов + `/skachat/` под каждый бренд — максимальный объём транзакционного трафика
2. 2-3 категорийных хаба (`s-live-stavkami`, `na-kriptovaljutu`, `s-vyvodom-na-uzcard-humo`) — быстро тестируют гипотезу с минимальными трудозатратами, переиспользуют уже готовые карточки
3. `/bonusy-i-promokody/` — закрывает большой незакрытый кластер спроса
4. `/otzyvy/` с формой добавления — долгосрочный актив, чем больше отзывов, тем сильнее сигнал
5. `/uz/` — самая ресурсоёмкая, но самая объёмная по неохваченному спросу
6. `/o-nas/`, `/faq/`, `/otvetstvennaya-igra/` — низкие трудозатраты, высокая отдача по доверию
